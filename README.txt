BACCARAT ANALYZER - ANDROID
=============================

Projeto Android em Java.

Como gerar o APK:
1. Abra a pasta BaccaratAndroid no Android Studio.
2. Espere o Gradle sincronizar.
3. Escolha Build > Build APK(s).
4. O APK estará em:
   app/build/outputs/apk/debug/app-debug.apk

A aplicação regista Jogador, Banca e Empate, mostra o histórico em círculos
e calcula estatísticas em tempo real. Não prevê resultados futuros.
